# Clervo roadmap

Clervo is building an execution layer for agents that need to discover a
capability, understand its cost and constraints, execute safely, and receive an
inspectable result.

Product direction includes AI and model routing, Research, Secure Sandbox,
Prediction Intelligence, Crypto Intelligence, Multi-chain RPC, MCP and SDK
interfaces, machine payments, receipts, provenance, and verification.

Current availability is intentionally not duplicated here. Use the live
[discovery](https://api.clervo.dev/.well-known/clervo.json),
[status](https://api.clervo.dev/status.json),
[pricing](https://api.clervo.dev/pricing.json), and
[model catalog](https://api.clervo.dev/v1/models).

## Direction

- Broaden reliable capability coverage while unavailable dependencies fail
  closed.
- Strengthen authorization, idempotency, replay, reconciliation, receipts, and
  result verification.
- Improve runtime resilience without overstating availability.
- Keep the API, SDKs, MCP surface, documentation, and generated discovery in
  sync with serving behavior.
- Add public capabilities only after technical qualification and the required
  owner commercial, pricing, legal, contractual, or branding decision.

The owner sets product and business priorities. Repository milestones and old
verification records do not select engineering work.
