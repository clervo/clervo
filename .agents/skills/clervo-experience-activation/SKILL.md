# Clervo experience activation

1. Audit real routes, docs, contracts, lifecycle state, and supported
   integration methods.
2. Separate discovery, Proof Lab, and developer-operation navigation.
3. Implement one end-to-end deterministic sandbox activation slice before
   expanding branches.
4. Use evidence events for completion; never use page views or decorative
   progress.
5. Keep live, preview, unavailable, and deterministic fixture modes explicit
   and persistent.
6. Build resume, refresh, back/forward, deep-link, and error-recovery behavior.
7. Connect code actions to lifecycle state and non-payable preview receipts.
8. Compose mobile independently and keep the critical path keyboard/touch safe.
9. Add optional challenges only after the critical path is reliable.

Leave route/state maps and focused tests for fresh start, resume, deep links,
keyboard, mobile, representative failures, receipt inspection, and recovery.
Reject streaks, leaderboards, fake activity, modal tours, and primary navigation
hidden in 3D.
