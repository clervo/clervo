# Clervo final proof

1. Run relevant repository build, type, lint, and test commands.
2. Verify every intended route through direct load, navigation, history, and
   anchors.
3. Activate every visible control and CTA.
4. Test keyboard, focus, touch, 200% zoom, and reduced motion.
5. Test canonical desktop/mobile viewports and orientation changes.
6. Test slow network, low-power/static modes, missing WebGL, and context loss.
7. Compare forward, reverse, fast-scroll, and recovery captures with canonical
   visual states.
8. Run accessibility, crawl/schema, trace, console, and network checks.
9. Validate 3D assets and media provenance.
10. Fix failures and record only genuine residual deviations.

Do not declare visual completion without reproducible canonical source files.
