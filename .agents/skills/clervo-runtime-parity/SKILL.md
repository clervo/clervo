# Clervo runtime parity

1. Preserve meaning and controls in semantic HTML, CSS, and SVG.
2. Build one deterministic state model independent from scroll and renderer.
3. Map native scroll and direct interaction into that state; do not scroll-jack.
4. Use one persistent 3D instrument and exact named canonical cameras.
5. Keep quote, approval, evidence, receipt, recovery, and status DOM-owned.
6. Define each viewport state's physical change, DOM evidence, interaction,
   fallback, and Clervo-specific purpose.
7. Reject generic gradients, particles, glass cards, bento grids, and dashboard
   patterns that do not serve the mechanism.
8. Author mobile cameras, copy, controls, and evidence layouts independently.
9. Implement loading, reduced-motion, static, low-power, and context-loss modes.
10. Capture deterministic parity evidence and fix source causes rather than
    screenshot symptoms.
