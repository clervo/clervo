# Clervo cinematic production

1. Read `docs/product/CLERVO-V6-VISUAL-AUTHORITY.md` and the relevant V6 visual
   references; ignore reference copy as product truth.
2. Build and inspect matte-gray geometry before materials or glow.
3. Store exact named desktop and portrait cameras.
4. Author named mechanical actions aligned with deterministic runtime states.
5. Approve neutral material response before semantic light.
6. Build semantic light in causal order; avoid ambient loops.
7. Render required keyframes and an image sequence.
8. Preserve the motion-master timing/grade recipe and portrait reframe.
9. Use paid generative media only after explicit bounded-spend approval; record
   model, region, prompt, output, cost, and provenance.
10. Export, optimize, and validate GLB assets while preserving Blender sources,
    scripts, project files, and settings.
11. Compare browser captures against canonical references and fix geometry,
    camera, material, and state causes.

Generated media, compositor glow, and prerendered hero video cannot substitute
for canonical physical sources or functional runtime interaction.
