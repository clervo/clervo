# One ticket per Cline task

- One Cline task must correspond to one Clervo ticket and one acceptance result.
- Do not mix architecture redesign, provider research, feature implementation, container setup, branding, or future ideas into the same task.
- Begin by stating:
  - active ticket
  - one question
  - allowed files
  - acceptance command
  - stop condition
- If a new unrelated requirement appears, add it to the parking lot and continue the active ticket.
- When the ticket is completed or blocked, update evidence and stop. Do not automatically begin the next ticket.
- If context becomes noisy or the task starts repeating, create/update the durable active-ticket state file and move to a new task.
