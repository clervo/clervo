# Clervo Codex Autonomy Policy

Codex has autonomous technical permission inside the dedicated Clervo
development container and repository.

It may, without requesting command approval:

- inspect and modify Clervo repository files;
- run Git, npm, tests, verifiers, builds, and local services;
- install development dependencies required by an authorized ticket;
- use bounded network access required by an authorized ticket;
- create evidence, documentation, fixtures, and commits;
- repair ordinary repository, test, lint, typecheck, and tooling failures;
- complete the current authorized ticket and stop.

This permission does not override the Clervo master plan, stage order,
ticket scope, truthful-claims policy, or stop conditions.

Still prohibited unless the active ticket explicitly authorizes it:

- real USDC payments or wallet transactions;
- production deployment or production data mutation;
- cloud billing, IAM, account, or secret changes;
- revealing, logging, or committing secret values;
- deleting host backups or unrelated projects;
- beginning the next ticket automatically;
- beginning Stage 10 AI implementation, Stage 11 Sandbox implementation, or any later implementation stage before the active prior-stage and First Revenue Release gates authorize it;
- silently changing providers, product claims, or architecture;
- destructive Git history rewriting;
- bypassing provider terms, robots rules, access controls, or quotas.

Codex must implement, test, verify, document, commit, report, and stop
at the end of each authorized ticket.
