# Six-family commercial recovery destination

This path is retained for compatibility with older links. It is not permission
to skip the active recovery gates or require all six families before the first
truthful revenue.

## Destination

Clervo remains one platform with:

1. Search
2. AI
3. Secure Sandbox
4. Multi-chain RPC
5. Prediction
6. Crypto Intelligence

The long-term destination is an operation-level catalog in which every released
operation has qualified supply, useful output, exact pricing, bounded cost,
safe public access, payment where applicable, durable receipts, idempotent
replay, monitoring, recovery, and truthful distribution.

## Sequential commercial recovery

Products may reach revenue sequentially. Search is first in the current work
order, followed by AI, Secure Sandbox, Multi-chain RPC, Crypto Intelligence, and
Prediction.

First revenue does not complete the platform. Full platform completion does not
need to block the first operation that is honestly sellable.

## Active recovery gates

- Gate 5: reconcile operation-level market and runtime truth
- Gate 6: clean GitHub and public exposure
- Gate 7: collapse active authority
- Gate 8: rewrite the commercial launch roadmap
- Gate 9: recover products one vertical at a time
- Gate 10: integrate the replacement website

No fixed aggregate readiness percentage controls this program.

## Operation completion

A released operation needs source-bound proof for:

- identity, schema, and limits;
- provider rights and cost;
- useful runtime behavior and degradation;
- public lifecycle and route;
- price, approval, and hard charge ceiling;
- settlement when applicable;
- durable result, evidence, and receipt;
- idempotent no-charge replay;
- monitoring, failure recovery, and supportable capacity;
- truthful catalog and machine discovery.

Implementation proof, operational proof, payment proof, and external demand
proof remain separate.
