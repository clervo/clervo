# Superseded

The full-platform percentage and all-six-before-opening execution model are no
longer active authority.

Current execution is defined by:

- `docs/CURRENT-STATE.yaml`
- `docs/product/SHOP-OPEN-EXECUTION.md`
- `packages/catalog/launch-state.v1.json`

The six families remain permanent platform scope, but `search.web` opens first.
