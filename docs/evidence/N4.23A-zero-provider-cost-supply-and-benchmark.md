## Benchmark result

The fixed corpus SHA-256 is `04d171bfe04349dfb85280d923ccb06efaa8eb404d94ca0e5a58eaebbe05badb`. It covers static and JavaScript commerce, real estate, documentation, news, sitemap, RSS, redirect, robots denial, oversized response, unsupported MIME, and private/metadata targets.

- Scrapling returned HTTP 200 with the expected extracted marker for six static/XML cases. Per-process wall time ranged from 2.366 ms to 9.387 ms and observed peak RSS ranged from 47,636 to 47,992 KiB. The redirect remained HTTP 302 and was not followed.
- Crawl4AI rendered the required JavaScript marker in 1,010.363 ms, returned 368 bytes, observed 145,772 KiB peak RSS, and destroyed its temporary browser state.
- Meilisearch indexed four extracted-text documents in 311.596 ms; `Northstar` returned `static_commerce` as the required top hit in 9.761 ms. Total wall time was 416.468 ms and observed peak RSS was 334,464 KiB.
- The existing Clervo boundary rejected robots denial (`robots_disallowed`), 131,072 bytes over the 65,536-byte ceiling (`response_too_large`), binary MIME (`content_type_not_allowed`), loopback IPv4/IPv6, link-local metadata IP, and `metadata.google.internal` before qualification. These are contract-bound policy observations, not claims that raw Scrapling or Crawl4AI independently enforce the complete boundary.

The initial Meilisearch probe returned zero hits because the benchmark supplied raw HTML. The corrected boundary indexes deterministic extracted text, matching the planned worker→normalization→index pipeline, and retains the strict expected-top-hit assertion. No benchmark expectation was weakened.

## Lawfulness and cost truth

Only owner-approved, user-authorized, or otherwise explicitly permitted public sources may enter the focused frontier. Robots, honest crawler identity/contact, opt-out/removal, denylist, recrawl suppression, attribution, and fail-closed unresolved content use are mandatory. No login, cookie, CAPTCHA solving, stealth, proxy rotation, access-control bypass, public Nominatim resale, uncontrolled crawl, or Common Crawl archived body in paid output is selected.

Provider API cost for both core routes is exactly zero by contract. Infrastructure is not free: later tickets must measure and cap compute, storage, browser minutes, and egress and include them in customer pricing.
