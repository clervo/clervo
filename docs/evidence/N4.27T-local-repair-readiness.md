## Repair output

### Developer retrieval

The new adapter conservatively recognizes exact npm package and GitHub
`owner/repository` identities and uses their exact public metadata endpoints.
Only queries without an exact identity enter bounded normalized search. It
retains independent health/circuit/quota identity, two-request concurrency,
metadata-only normalization, rate-limit failure behavior, attribution and USD
0 provider API cash cost. A deterministic N4.27T staging entry replaces only
the developer adapter while preserving the other five unchanged source
adapters.

### Browser and hostile reliability

The new worker has explicit 2.5-second preflight, 6.5-second render, one-second
cleanup and 11-second supervisor budgets instead of a supervisor that could
expire before its child phases. It runs one fresh non-root Chromium process per
attempt behind the gateway, uses `tini` for reaping, a memory-backed `/dev/shm`,
a read-only root filesystem, bounded resources, a seccomp boundary and
process-group termination. It returns only a hash-bound receipt; hostile
content is labelled `untrusted_evidence_only` and never returned as authority.

### Resource overlap

The resource admission gate requires a fresh complete inventory, zero unknown
resources, zero-resource evidence, terminal deletion operations and an exact
candidate plan within USD 5/day before an external create may even be proposed.
It rejects asynchronous delete/create overlap, active resources, pending or
unknown operations, stale inventory, duplicate/unlabelled candidates and
combined exposure above the ceiling. Its receipt explicitly states that it
does not authorize an external action.
