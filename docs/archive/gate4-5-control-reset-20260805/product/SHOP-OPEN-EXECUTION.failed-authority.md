# Shop-Open execution

## Goal

Open `search.web` as the strongest sellable product the existing Clervo
technology can support.

## Order

1. Collapse obsolete control authority.
2. Trace the existing Search buying path.
3. Keep, connect, or fix existing components.
4. Synchronize launch state and all generated visibility surfaces.
5. Confirm the offer, price, and hard cost ceilings.
6. Run a fresh real production result.
7. Complete one owner-approved wallet payment.
8. Verify the result, receipt, and same-key replay.
9. Complete another new paid request.
10. Publish and distribute the working offer.

## Completion

The shop is open when the real production path can repeatedly accept money and
deliver the purchased useful outcome with consistent public visibility.

No external tester is required before opening.
