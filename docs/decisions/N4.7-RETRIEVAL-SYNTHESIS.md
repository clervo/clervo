# N4.7 bounded retrieval synthesis decision

Date: 2026-07-30

## Decision

Treat all assembled evidence as untrusted data at the model boundary. The adapter receives a frozen request that explicitly disables tools and external actions, requires ignoring instructions found in evidence, and requires one or more existing citation IDs for every claim. The assembly and its expected canonical hash are revalidated before the adapter can run.

Adapter output is not accepted as prose. It must be the exact bounded claims-only shape; citation identities must be known and unique per claim. Only after complete validation does Clervo deterministically assign claim IDs, render the answer, and copy exact citation/provenance records from the assembly. Any invalid output, timeout, cancellation, or adapter exception returns no claims, citations, or answer.

## Explicit exclusions

- This is an enforceable interface and output-validation boundary, not proof that a live model can never follow prompt injection or fabricate a semantically unsupported sentence.
- No model is selected, qualified, invoked, or billed.
- No tools, browsing, external actions, persistence, HTTP route, payment, cloud, IAM, or deployment are introduced.

## Rejected alternatives

- Pass extracted pages as trusted instructions: rejected because retrieved content is attacker-controlled data.
- Accept free-form answer text and repair citations afterward: rejected because uncited partial output could escape.
- Trust a caller-provided assembly digest without reconstructing assembly invariants: rejected because evidence/provenance substitution must fail before invocation.
