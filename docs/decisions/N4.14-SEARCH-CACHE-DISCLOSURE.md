# N4.14 Search Cache Disclosure

## Decision

Every public `SearchResponse` carries a `search_cache_disclosure_v1` artifact. The artifact distinguishes an origin/cache miss, a fresh cache hit, and a stale entry that was successfully revalidated before use. It binds the disclosure to a canonical query plus requested result bound and to the exact returned response material, excluding the disclosure itself to avoid a circular hash.

The current recorded pipeline does not implement durable result caching, so it emits `outcome: "miss"`. This is intentional: N4.14 makes cache behavior externally auditable without claiming infrastructure that does not exist. A future cache may supply hit evidence through `CreateSearchResponseInput.cache`, but the constructor rejects future-dated timelines, expired fresh-hit claims, stale-revalidation claims that were not actually stale, and revalidations not current at response generation.

## Freshness semantics

- `ageSeconds` is whole elapsed seconds since the representation was last validated.
- `residentAgeSeconds` is whole elapsed seconds since it was stored.
- A `fresh_hit` requires `ageSeconds < freshnessLifetimeSeconds`.
- A `stale_revalidated` entry requires the previous validation to be at least one freshness lifetime old at revalidation, and `validatedAt` must equal `observedAt`.
- `freshnessRemainingSeconds` is explicit and recomputed by verification.
- `miss` has zero lifetime, age, resident age, and remaining freshness, and carries no storage timestamps.

## Trust boundary

`assertSearchExecutionOutput` verifies the disclosure against the executor input before HTTP output or receipt construction. Request-bound, response-bound, timestamp, and derived-age tampering therefore fail closed.

## Rejected alternatives

- Claim a cache hit for idempotency replay: rejected because idempotency replay is an operation replay, not retrieval-result cache reuse.
- Add an in-memory result cache solely for this milestone: rejected because it would not be durable across processes and would overstate production behavior.
- Emit only a boolean `cached`: rejected because it cannot disclose age, freshness, revalidation, or representation binding.
