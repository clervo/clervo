# N4.8 recorded search benchmark decision

Date: 2026-07-30

## Decision

`evaluateSearchBenchmark` is a pure repository-local acceptance boundary over recorded `SearchResponse` and `RetrievalSynthesisReport` observations. It validates observation/query/operation binding, requires all six quality and resilience categories, hashes only corpus identity and ground truth, and independently recomputes metrics rather than trusting self-reported scores.

Content metrics exclude the provider-failure category because an expected graceful failure has no evidence to retrieve. Latency and cost include every case. Injection and provider-failure metrics are evaluated only on their dedicated categories. Citation validity is rechecked against exact evidence offsets; expected synthesis with no cited claims scores zero. A pass requires every configured absolute threshold and the minimum named-baseline improvement.

## Explicit exclusions

- The included six-case corpus is deterministic acceptance evidence, not a statistically calibrated relevance benchmark, production SLO, or live-provider comparison.
- `costMicrousd` and `latencyMs` are recorded observation fields whose bounds and aggregation are verified; this ticket does not meter real provider/model billing or measure network latency.
- The named baseline is BlockRun-compatible repository-local behavior, not an execution of the legacy runtime or a claim about its current production quality.
- No live Brave/Common Crawl adapter, external fetch, browser, model, human labeling service, database, queue, HTTP route, payment, cloud, IAM, or deployment is introduced.

## Rejected alternatives

- Trust candidate-provided aggregate metrics: rejected because acceptance must independently recompute evidence-grounded outcomes.
- Mix failure cases into recall/freshness denominators: rejected because graceful failure behavior is a separate requirement and contains no retrievable evidence.
- Hash recorded candidate/baseline outputs into corpus identity: rejected because the same ground-truth corpus must compare multiple systems without changing identity.
- Claim live quality from synthetic fixtures: rejected because repository-local determinism is not production evidence.
