# N4.4 — Build isolated deterministic extraction and content-level near-duplicate detection

## Ticket

- **Stage:** 4 — Search vertical slice.
- **One question:** Can hash-bound fetched bytes be converted into deterministic normalized evidence in a bounded non-executing worker and deduplicated by content without beginning synthesis?
- **Inputs allowed:** controlling plan; repository-local N4.1–N4.3 contracts and fixtures. No live provider, browser, credential, billable call, cloud/IAM mutation, legacy runtime, or model.
- **Freshness date:** 2026-07-30.
- **Secrets involved:** none.

## Decision

Require a successful hash/length/MIME/final-URL-bound fetch receipt, support deterministic UTF-8 text and non-executing HTML/XHTML extraction in a bounded worker thread, preserve exact normalized-text offsets, label instruction-like content as untrusted data, and perform order-independent exact-hash plus five-word-shingle Jaccard deduplication with explicit integer thresholds and accounting.

## Build output

- Extraction request/record/segment and deduplication TypeScript contracts, worker implementation, validation, hashing, similarity, deterministic winner selection, and deep immutability.
- One strict Draft 2020-12 extraction/deduplication schema, positive fixture, and false-duplicate negative fixture.
- Ten focused tests covering active-content removal, entity/Unicode/whitespace normalization, offsets, instruction-like evidence, fetch binding, unsupported/malformed/empty/oversize failure, similarity, exact/near accounting, order independence, forged inputs, bounds, and immutability.
- Deterministic generated OpenAPI/schema artifacts plus decision, ticket, journal, README, and controlling-plan handoff.

## Validation contract

- **Focused tests:** `npm run contracts` and `npm run test:n4.4`.
- **Failure test:** rejected/forged/mismatched fetch evidence, unsupported MIME, invalid UTF-8, malformed active regions, empty or oversized output, worker timeout, forged normalized hashes/offsets, duplicate IDs, unsafe thresholds, and unbounded batches fail closed.
- **Acceptance command:** `npm test`, `npm run generate:discovery`, source/generated schema semantic parity, `npm run staging:smoke`, and `git diff --check`.
- **Cost/network effects:** repository-local validation only; no provider, crawler, browser, model, cloud/IAM/deployment mutation, wallet/payment, external traffic, or USDC spend.
- **Parking lot:** PDF/JSON/OCR extraction; browser/JavaScript isolation; calibrated boilerplate/language handling; model-facing prompt-injection defense; query rewriting; parallel federation; synthesis; benchmarks; HTTP/mock-paid integration.
