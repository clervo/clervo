# N4.2 — Qualify two independent retrieval paths

## Ticket

- **Stage:** 4 — Search vertical slice.
- **One question:** Can two independently operated retrieval paths be selected and gated by evidence-dated terms/technical checks while defining a fail-closed retrieval/extraction safety boundary?
- **Inputs allowed:** controlling plan; repository-local contracts; bounded read-only official provider documentation. No billable calls, credentials, crawler/browser execution, cloud/IAM mutations, or legacy runtime.
- **Freshness date:** 2026-07-30.
- **Secrets involved:** credential names only; no values were available or read.

## Decision

Provisionally select Brave Search API as primary and Common Crawl URL Index/archive as fallback. Keep both live gates closed until credentialed/API and bounded archive probes satisfy every qualification check. Implement the qualification and target-safety decision contracts now so later adapters cannot convert mere selection into false readiness.
