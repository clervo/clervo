# N4.6 — Assemble bounded retrieval evidence with ranking, citations, and provenance

## Ticket

- **Stage:** 4 — Search vertical slice.
- **One question:** Can qualified federation observations pass through bounded fetch, isolated extraction, content deduplication, deterministic ranking, and exact citation binding while preserving end-to-end per-path provenance and not beginning synthesis?
- **Inputs allowed:** controlling plan; repository-local N4.1–N4.5 contracts and fixtures. No live provider, credential, billable call, archive object read, browser, model, cloud/IAM mutation, legacy runtime, or payment.
- **Freshness date:** 2026-07-30.
- **Secrets involved:** none.

## Decision

Add one deterministic assembly boundary that reconstructs qualification, validates federation provenance before fan-out, owns explicit candidate/result/byte/output/worker/deadline bounds, invokes the existing N4.3 fetch and N4.4 extraction contracts, performs one content-deduplication batch, ranks only retained evidence through N4.1, verifies exact citations, and emits immutable terminal accounting plus full result-to-path/body/extraction provenance with synthesis structurally disabled.

## Build output

- Retrieval-assembly input, candidate-terminal-state, result-provenance, and report TypeScript contracts and implementation.
- Qualification/federation revalidation, deterministic IDs/order, assembly-owned dependency deadlines, candidate-local failures, batch content deduplication, deterministic ranking, exact citation verification, terminal accounting, and deep immutability.
- One strict Draft 2020-12 assembly schema, positive fixture, and false-ranked negative fixture.
- Eight focused tests covering real worker extraction, deterministic ranking/citations, exact/near duplicates, candidate-local fetch/extraction failure, non-cooperative dependency timeout, limits, forged provenance/qualification, closed content-use gates, bounds, and immutability.
- Deterministic generated OpenAPI/schema artifacts plus decision, ticket, journal, README, and controlling-plan handoff.
