# N4.19 — Provider-neutral lawful free-first retrieval supply

## Ticket

- **Stage:** 4 — Search vertical slice remediation.
- **One question:** What is the smallest provider-neutral contract and qualification change required so Clervo search is not locked to paid Brave while preserving all completed Stage 4 guarantees?
- **Freshness date:** 2026-07-31.
- **Secrets involved:** none.

## Decision

Add one provider-neutral retrieval-supply decision beside the completed retrieval, safety, provenance, normalization, deduplication, ranking, citation, synthesis, benchmark, deployment, and stage-exit contracts. Do not alter those completed contracts.

Ready free-first supply requires a selected self-hosted metasearch broker with at least two independently qualified upstream provider identities and direct independently qualified Common Crawl archive access. Public shared SearXNG deployments are ineligible. Brave is an optional exact-identity adapter whose absence or unqualified state does not block readiness. Common Crawl cannot be hidden behind the broker or share an upstream failure domain.

Crawl4AI was the sole extraction worker evaluated from its official repository. It remains unselected: current primary-source evidence establishes its Apache-2.0 crawler/browser role but does not prove Clervo's deterministic fixtures, enforced timeouts, resource caps, and fail-closed isolation. ScrapeGraphAI, Agent Browser, browser-use-style tools, and Agent Reach remain deferred, non-core candidates.

## Primary-source notes

- SearXNG is operator-configured metasearch software. Each enabled engine carries separate configuration such as credentials/tokens, timeout, retry, network, weight, and disabled/inactive behavior.
- SearXNG documents rate limiting because upstream engines may CAPTCHA or block broker-origin traffic. Public shared instances therefore cannot be assumed to provide controlled production supply.
- Common Crawl provides its own URL Index and archive data path under separate terms and infrastructure. It remains a direct archive/corpus failure domain rather than a broker engine.
- Crawl4AI's official repository describes an Apache-2.0 browser/crawler and extraction worker. Two official documentation paths returned 404, so no broader repository survey or installation was performed.
