# N4.7 — Build bounded citation-preserving retrieval synthesis

## Ticket

- **Stage:** 4 — Search vertical slice.
- **One question:** Can ranked assembly evidence cross a model-facing boundary as untrusted data only, with no tools or external actions, while every accepted claim remains bound to an existing mechanically verified citation?
- **Inputs allowed:** controlling plan and repository-local N4.1–N4.6 contracts. No live model/provider call, external fetch, cloud/IAM mutation, deployment, wallet, payment, or USDC spend.
- **Freshness date:** 2026-07-30.
- **Secrets involved:** none.

## Decision

Add a removable synthesis adapter behind a fixed request policy: evidence is untrusted data, embedded instructions must be ignored, tools and external actions are disabled, every claim requires known citation IDs, and all sizes/deadlines are bounded. Revalidate the assembly and its expected hash before invocation; accept only the exact claims-only response shape; render the answer deterministically after validation; expose no partial answer on any failure.

## Build output

- Immutable synthesis request/report contracts with assembly hash binding and exact result/citation/provenance preservation.
- Safe `synthesized`, `insufficient_evidence`, `failed`, and `cancelled` outcomes with fixed invocation/failure codes.
- Strict Draft 2020-12 schema, valid and uncited-invalid fixtures, eight focused adversarial tests, exports, and canonical test wiring.

## Validation contract

- **Focused tests:** `npm run contracts` and `npm run test:n4.7`.
- **Failure test:** fabricated/duplicate/missing/uncited citations, extra fields, empty/oversized claims, forged assembly hashes/provenance, cancellation, non-cooperative adapters, and adapter exceptions fail closed without partial output.
- **Cost/network effects:** repository-local validation only; no live model/provider/external call, cloud/IAM/deployment mutation, wallet/payment, or USDC spend.
- **Parking lot:** model qualification; live prompt-injection evaluation; semantic entailment checking; benchmark corpus; HTTP and payment exposure.

## Completion

- **Result:** repository-local synthesis boundary implemented; instruction-like evidence is passed only under the fixed untrusted-data/no-tools policy, and accepted output is citation-preserving and immutable.
- **Focused tests:** `npm run test:n4.7` passed 8/8.
- **Exact next ticket:** N4.8 — benchmark recorded search quality against a named BlockRun-compatible baseline; do not begin HTTP/payment exposure.
