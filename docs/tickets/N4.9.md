# N4.9 — Expose bounded free-sample and mock-paid search HTTP routes

## Ticket

- **Stage:** 4 — Search vertical slice.
- **One question:** Can the completed deterministic search contracts be invoked over bounded loopback HTTP with replay-safe free sampling, an explicitly non-payable default paid route, and a test-only N2.2 mock-paid completion seam without claiming public deployment or real payment readiness?
- **Inputs allowed:** repository-local N1.1–N4.8 contracts, loopback HTTP, recorded executor output, and mock payment evidence. No live provider/model/browser call, external traffic, cloud/IAM/deployment mutation, wallet/facilitator use, real payment, or USDC spend.
- **Freshness date:** 2026-07-30.
- **Secrets involved:** none.

## Decision

Implement strict shared search request/result contracts, a Node.js loopback-capable adapter with injected execution, bounded free quota and idempotent replay, default non-payable N2.1 paid challenges, and an explicit test-only N2.2 completion path. Publish only `search.query` and the two exact paths in versioned generated OpenAPI, discovery, catalog, schemas, and `llms.txt` while retaining false deployment/payment claims.

## Build output

- Shared request normalization, route-bound canonical hashing, output/citation binding, result envelopes, and process-local free quota reference mechanics.
- `POST /v1/search/free` and `POST /v1/search/paid` HTTP adapter paths with RFC 9457-shaped failures, replay/conflict handling, quotas, non-payable challenges, and injected mock-paid receipts.
- Two strict Draft 2020-12 schemas, three fixtures, generated catalog/discovery updates, N1.3 truth assertions, and five focused N4.9 tests.

## Validation contract

- **Focused tests:** `npm run contracts`, `npm run test:n1.3`, and `npm run test:n4.9`.
- **Failure test:** unknown fields, query parameters, idempotency conflicts, quota exhaustion, forged executor bindings, payment-looking input without explicit injection, and false discovery payment claims fail closed.
- **Acceptance command:** `npm test`, `npm run staging:smoke`, and `git diff --check`.
- **Cost/network effects:** repository-local and loopback validation only; no external traffic, provider/model/browser call, cloud/IAM/deployment mutation, wallet/facilitator/real payment, or USDC spend.
- **Parking lot:** durable distributed idempotency/quota storage; live executor orchestration; public server/deployment verification; real x402 verification/authorization/settlement; streaming/SSE; production observability and load tests.
