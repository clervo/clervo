# N4.3 — Build the bounded retrieval/fetch safety adapter

## Ticket

- **Stage:** 4 — Search vertical slice.
- **One question:** Can HTTP(S) retrieval enforce DNS/socket, redirect, robots, deadline, MIME, byte, and content-use boundaries while producing immutable evidence receipts?
- **Inputs allowed:** controlling plan; repository-local N4.2 contracts; non-billable public qualification endpoints. No credentials, billable calls, browser/parser execution, cloud/IAM mutations, or legacy runtime.
- **Freshness date:** 2026-07-30.
- **Secrets involved:** none.

## Decision

Implement one provider-neutral bounded fetch function with an injectable DNS/transport boundary and a pinned-address Node.js transport. Resolve and validate every robots/content redirect hop, require the connected socket address to equal the selected public DNS answer, enforce one absolute deadline and streaming byte ceilings, fail closed on robots uncertainty and unsupported MIME/content use, and emit an immutable hash-bound receipt. Permit explicit robots `not_applicable` only for archive replay; this does not grant content-use rights.

## Build output

- Retrieval fetch request/dependency/result/receipt TypeScript contracts and a default pinned-address HTTP(S) transport.
- Robots retrieval/cache/matching with longest-user-agent and normalized-rule precedence.
- One strict Draft 2020-12 fetch-receipt schema, a positive fixture, and a false-success negative fixture.
- Fourteen focused tests covering success, DNS/connection rebinding, redirects, robots, percent encoding, deadlines, MIME, byte ceilings, unsafe request bounds, archive policy, receipt immutability, and failed-hop preservation.
- Deterministic generated OpenAPI/schema artifacts plus ticket, decision, journal, README, and controlling-plan evidence.

- **Failure test:** unsafe DNS answers, connected-address mismatch, unvalidated redirects, unavailable/disallowing robots, weaker user-agent precedence, encoding-based rule precedence, unsupported content use/MIME, declared/streamed oversize bodies, stalled DNS/connect/body operations, unsafe headers, and unauthorized robots bypass fail closed.
- **Acceptance command:** `npm test`, `npm run generate:discovery`, source/generated schema parity, `npm run staging:smoke`, and `git diff --check`.
- **Cost/network effects:** one bounded public Common Crawl collection-index request plus repository-local validation; no credential, billable provider call, archive object read, cloud/IAM/deployment mutation, wallet/payment, or USDC spend.
- **Parking lot:** credentialed Brave qualification; Common Crawl URL-index lookup and byte-range archive read; parser/browser isolation; HTML/PDF extraction; prompt-injection boundaries; normalized-content near-duplicate removal; query rewriting; parallel federation; synthesis; benchmarks; HTTP/mock-paid integration.
