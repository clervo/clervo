# N5.1 — Live Intelligence canonical registry foundation

## Ticket

- **Stage:** 5 — Live Intelligence productization and platform-registry foundation.
- **One question:** Can one fail-closed registry distinguish pillar, capability, operation, product and SKU truth while preventing internal or sealed schemas from leaking into public projections?
- **Inputs allowed:** the proven Stage 4 contracts, six-product launch authority, existing repository-local preview projection, JSON Schema Draft 2020-12, and OpenAPI 3.1.1. Stage 4 final evidence is read-only.
- **Files allowed to change:** `packages/catalog/**`, the N5.1 contract/schema/fixtures/export, the preview generator and its focused tests, product-scope capability synchronization, package scripts, this ticket, active dispatch state, append-only journal, and the external master-plan handoff.
- **Freshness date:** 2026-08-01.
- **Secrets involved:** none. The separately owner-authorized `/workspace/import` normalization is outside Git and is not a registry input.

## Preflight and decision

JSON Schema Draft 2020-12 remains the repository contract dialect. OpenAPI 3.1.1 inherits Draft 2020-12 processing and requires explicit types because keywords and formats do not imply a type. N5.1 therefore keeps canonical `$id` URI references, strict object closure, and an explicit per-schema visibility manifest rather than filename inference.

The registry is an internal, unfrozen foundation. It records all six stable pillars and their adopted capability identifiers, but only instantiates operations, products, routes, and SKUs already supported by Stage 4 contracts. Registry identity does not establish availability. Existing preview generation may consume only schemas classified `public_wire`; `internal_control` and `sealed_evidence` are excluded. This hardens the existing preview generator and does not begin the Stage 13 final discovery system.

- **Failure test:** reject missing/duplicate entities, dangling references, invented availability, paid SKUs without a maximum charge, unknown schema files, and any internal/sealed schema selected for public projection.
