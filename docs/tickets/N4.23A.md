# N4.23A — Zero-provider-cost supply amendment and bounded tool benchmark

## Ticket

- **Stage:** 4 — Search vertical slice remediation.
- **One question:** Which smallest Clervo-controlled crawler, JavaScript fallback, and open-core index configuration can replace every required paid general-Web search API dependency without weakening the 21-check Stage 4 gate?
- **Freshness date:** 2026-07-31.
- **Secrets involved:** none.

## Decision

Select Scrapling 0.4.12 as the default non-stealth HTTP/frontier worker, Crawl4AI 0.9.2 with Playwright 1.61.0 as an internal-only provisional JavaScript fallback, and Meilisearch 1.51.0 community features as the first focused index. Clervo owns URL policy, fetch authorization, normalization, ranking, provenance, health, cost caps, and public contracts.

The two planned route identities are `clervo.focused-index.v1` and `clervo.live-federation.v1`. Their discovery dependency, index state, health identity, and failure domain must remain independent. Selection is development evidence only: neither route is implemented, staging-qualified, available, or Stage 4-ready in this ticket.

Public Nominatim remains excluded from production. Common Crawl metadata may support URL/historical discovery, but archived bodies remain development-only and cannot appear in paid output. No hosted or eventually-paid search provider is a required dependency.

## Build output

- A strict source contract/schema and deterministic success/failure fixtures for the zero-provider-cost decision.
- A bounded loopback corpus and repeatable benchmark harness for Scrapling, Crawl4AI, Meilisearch, and the existing Clervo retrieval boundary.
- Exact pins, licenses, artifact hashes, latency/resource observations, failure behavior, and the 21-check architecture mapping.
- A historical amendment to the N4.23 owner-action package; its original research remains intact.

## Stop condition

Commit N4.23A, synchronize the handoffs, and stop. Per `AGENTS.md`, do not start N4.23B in the same ticket.
