# N1.3 — Generate and test OpenAPI and discovery

## Ticket

- **Stage:** 1 — Contracts, catalog, and operations
- **One question:** Can Clervo generate deterministic, machine-readable OpenAPI and discovery artifacts from its existing contracts without inventing live endpoints, payment behavior, products, or deployment claims?
- **Why it blocks the stage:** Commerce and later vertical slices need one reviewable public contract surface, while false availability claims would make every downstream integration unsafe.
- **Inputs allowed:** controlling plan; completed N1.1/N1.2 contracts; official OpenAPI 3.1.1 evidence; the current `llms.txt` proposal; repository conventions. No legacy runtime implementation or state.
- **Preflight scope:** OpenAPI root/schema requirements, JSON Schema reuse, deterministic generation, preview lifecycle wording, discovery truthfulness, secret safety, and local tooling.
- **Research limit:** 20 minutes; no competitor or provider survey.
- **Freshness date:** 2026-07-30.
- **Secrets involved:** none.

## Decision

Generate OpenAPI 3.1.1, `/.well-known/clervo.json`, `/llms.txt`, and versioned public schema copies from the existing contract source. Until HTTP and commerce exist, OpenAPI has no paths or server claim; discovery is `contract_preview`, non-callable, product-empty, payment-unimplemented, settlement-unverified, and deployment-unverified. Generation rejects false readiness claims.

## Build output

- TypeScript OpenAPI/discovery/llms generators and fail-closed preview assertions.
- Deterministic generated public artifacts containing nine exact Draft 2020-12 schemas.
- Six focused tests for OpenAPI shape, schema compilation/copy parity, discovery truth, `llms.txt` structure, injected false-live claims, and common secret material.
- ADR-0006, ticket evidence, journal/README updates, and next-ticket handoff.

## Validation contract

- **Focused tests:** build; generate twice deterministically; verify required OpenAPI fields and empty paths; compile every embedded schema; prove public schema copies equal sources; verify discovery and `llms.txt` equal generator output.
- **Failure test:** injected callable or payment-ready state must make the preview assertion throw before artifacts are written.
- **Acceptance command:** `npm test` under Node.js 24.
- **Cost/network effects:** three bounded read-only specification requests, one of which returned 404; local generation/tests only; no provider, cloud, IAM, deployment, or payment mutations; 0 USDC.
- **Evidence produced:** source, generated artifacts, tests, ADR, ticket, journal, README, and controlling handoff.
- **Parking lot:** HTTP artifact serving; product paths and schemas; examples; security schemes; x402 challenge/discovery; quotes, ledger, settlement, SDK/MCP generation, live deployment verification.
- **Stop condition:** focused and full acceptance pass, artifacts/evidence are committed, handoff names N2.1, then stop.
