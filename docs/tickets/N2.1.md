# N2.1 — Build quote and mock x402 challenge

## Ticket

- **Stage:** 2 — Commerce core
- **One question:** Can Clervo bind a visible maximum charge to an exact request and emit a deterministic x402 v2-shaped mock 402 challenge without accepting or claiming a real payment?
- **Why it blocks the stage:** Ledger, replay, settlement, and reconciliation require an immutable quote/challenge boundary before any authorization or side effect.
- **Inputs allowed:** controlling plan; N1.1/N1.2 contracts; official x402 v2 core and HTTP transport specifications; repository conventions. No legacy runtime state, wallet, facilitator, or provider.
- **Preflight scope:** quote fields/hash/expiry, maximum-charge enforcement, x402 v2 initial PaymentRequired shape/header, and mock-readiness guard.
- **Research limit:** 20 minutes; one corrected official repository lookup; no provider or competitor survey.
- **Freshness date:** 2026-07-30.
- **Secrets involved:** none.

## Decision

Add a strict hash-bound quote and an offline x402 v2-shaped challenge. The challenge uses the canonical `PAYMENT-REQUIRED` base64 header but only `mock:*` network/payee identifiers, declares itself non-payable, and rejects every readiness claim. It cannot accept a signature, authorize work, contact a facilitator, execute a product, or settle.

## Build output

- Quote and mock PaymentRequired TypeScript contracts, hashing, validation, deterministic header encoding, and 402 response construction.
- Two strict Draft 2020-12 schemas and four positive/negative fixtures.
- Seven focused tests for quote integrity, timestamps, x402 shape, header round-trip, expiry/timeout, asset/payee safety, and injected false readiness/binding changes.
- ADR-0007, ticket evidence, journal/README updates, generated schema/OpenAPI refresh, and next-ticket handoff.

- **Acceptance command:** `npm test` under Node.js 24.18.1.
