# Skills inventory

The immediately discoverable Clervo catalog contains three safety and design
skills. Ordinary engineering follows `AGENTS.md` directly:

| Skill | Trigger and unique role |
| --- | --- |
| `clervo-cloud-cleanup` | prove ownership, dependency-ordered teardown, cost closure, and zero-resource checks |
| `clervo-x402-proof` | fail closed without explicit owner payment approval; prove authorization, settlement, replay, and reconciliation |
| `clervo-design-studio` | encode the Clervo brand with truthful UI evidence, accessibility, responsive behavior, motion, and performance |

The retired engineering-stage, benchmark-freeze, and release-handoff skills are
preserved under `docs/archive/process-control/nplan4/skills/` and are not in the
automatic skill catalog.

Additional workflow skills should add a distinct technical capability rather
than process authorization or task-by-task stopping.
